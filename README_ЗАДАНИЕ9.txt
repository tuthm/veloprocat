КАК УСТАНОВИТЬ
1. Скопируйте содержимое архива в папку проекта zanyatie7_veloprokat
   (с заменой файлов).
2. В терминале проекта, в окружении venv:

     python manage.py migrate
     python manage.py runserver

   В выводе migrate должна появиться строка:
     Applying main.0002_booking_contact... OK

3. Проверка:
   - каталог: ввод в "Поиск по модели" перерисовывает карточки без
     перезагрузки страницы (fetch на /api/units/);
   - карточка любой единицы: выбор дат пересчитывает "Итого" на лету;
   - та же страница: форма брони видна после входа demo / demo12345;
     пустой телефон/почта/даты и телефон не в формате +7XXXXXXXXXX
     дают красные подсказки под полями ещё до отправки;
     при отправке Django перепроверяет то же самое на сервере;
   - успешная отправка: бронь появляется в кабинете, статус "Новая".
