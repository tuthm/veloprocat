ЗАДАНИЕ 8 — СТРАНИЦЫ И АДАПТИВНОСТЬ. Что добавилось против занятия 7:
1. Страниц — 8: главная, каталог, карточка единицы, цены, о прокате, контакты, кабинет, поиск.
2. Данные из базы: модели Category, BikeUnit, Booking. Главная и каталог — циклом {% for %} по моделям.
   Фильтры шаблонов: date:"d.m.Y" и floatformat в кабинете, truncatechars в карточках.
   Пагинация по 20: при 31 записи каталог даёт страницу 1 (20) и страницу 2 (11).
3. Flexbox: сетки каталога, категорий, подвала — display:flex.
4. Адаптивность: брейкпоинты 360/768/1024/1440, ниже 768 — бургер.
5. Картинки: PNG 640x480 по ~6 КБ, width/height у всех img, loading="lazy" ниже первого экрана.
6. CSS один файл, переменные :root из UI-kit занятия 6.
